# English Letter Writing Practice

Static bilingual handwriting practice web app.

## Included
- Traditional Chinese / English UI
- Print uppercase / lowercase
- Cursive uppercase / lowercase
- Stroke order
- Trace mode
- Free writing mode
- Glass pill buttons
- Responsive layout

## GitHub Pages
1. Upload the files in this folder to a GitHub repository.
2. Go to Settings → Pages.
3. Choose Deploy from a branch.
4. Select `main` and `/ (root)`.
5. Save.

## Hostinger
Upload `index.html` to your domain/subdomain's `public_html` folder.

No build process is required.
